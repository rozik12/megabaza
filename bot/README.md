# MEGABAZA Telegram-бот (RU / UZ / EN)

**Для клиента:** каталог (52 образцовых товара: шины, диски, аксессуары, услуги) · прайс-лист текстом и файлом CSV · поиск по размеру/названию/авто ·
подбор шин по размеру, по автомобилю, по сезону · «моя машина» · хиты, акции, значки 🔥🏷🆕 · фильтры по цене и сезону, сортировка, страницы ·
сравнение товаров · избранное · «сообщить о поступлении» · комплект ×4 со скидкой · корзина, промокоды · оформление в один поток
(сохранённые телефон и адрес, доставка/самовывоз, геолокация, время получения, оплата, комментарий) · баллы лояльности (1% кэшбэк, оплата до 30%) ·
мои заказы, повтор, отмена, оценка · приглашение друзей (5% другу, 5 000 баллов вам) · чат с менеджером (фото, голос, файлы) ·
полезное: как читать размер шины, лето/зима, доставка, гарантия, FAQ · контакты, открыто/закрыто, карта, контакт магазина ·
inline-поиск `@бот 205 55` · напоминание о забытой корзине · язык, отписка от рассылок, удаление данных.

**Для админа** (`ADMIN_IDS`): `/admin` · заказы с кнопками статусов (клиент получает уведомление) · ответ клиентам любым типом сообщений ·
статистика и итоги дня в 20:00 · остатки (вкл/выкл) · `/setprice`, `/setstock`, `/sale`, `/unsale`, `/hit`, `/promo`, `/delpromo`, `/order`, `/export` ·
фото товара (фото с подписью `/photo id`) · рассылка `/broadcast` · предупреждение о низком остатке и низкой оценке.

Inline-режим включите в @BotFather: `/setinline`.

## Запуск на VPS
    cp .env.example .env   # заполните BOT_TOKEN и ADMIN_IDS
    docker compose up -d --build
    docker compose logs -f

Без Docker: `BOT_TOKEN=... ADMIN_IDS=... node bot.js` (Node 18+, зависимостей нет). Состояние (клиенты, заказы, корзины) хранится в `state.json`.

## Каталог
Файл `catalog.json` генерируется `python3 make_catalog.py` (названия на 3 языках). Замените цены и товары своими.

## Railway Functions
`python3 make_railway.py` собирает `railway.ts` (всё внутри одного файла). Состояние там хранится в памяти и сбрасывается при перезапуске.
